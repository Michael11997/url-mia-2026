# Respuestas - Laboratorio No. 2

## 1. ¿Qué función cumple File.ReadAllLines()?

Lee todas las líneas de un archivo de texto y las almacena en un arreglo de cadenas para poder procesarlas.

## 2. ¿Para qué sirve Split(',')?

Sirve para dividir una cadena de texto utilizando la coma como separador, obteniendo cada dato en una posición diferente del arreglo.

## 3. ¿Qué ventaja tiene utilizar una List<Estudiante>?

Permite almacenar varios objetos de tipo Estudiante de forma dinámica, facilitando agregar, recorrer y manipular los datos.

## 4. ¿Qué es JSON y para qué se utiliza?

JSON es un formato ligero para almacenar e intercambiar datos entre aplicaciones y sistemas.
